## Overview
In this study, the development of a drone simulation was made, with the capabilities to avoid countermeasures. The goal of this simulation is to understand possible vulnerabilities in existing countermeasure systems to help strengthen the defense capabilities. Throughout the development, Matlab Simulink was used to represent a drone model that was flown in a virtual environment. At the end it become clear the creating an avoidance system is not only possible, but should be something that countermeasure development should keep in mind.
