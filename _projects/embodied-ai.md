## Overview
This project examines a search and rescue task for a self-designed mobile robot. The mobile robot must be built with the Lego Mindstorm EV3 kit provided. The robot’s
design should enable it to move around in a given environment. Additional sensor inputs from the kit should be employed to create a behavior-based architecture. The
primary task for the robot is to navigate in a given map, following specific lines to reach the object that needs to be rescued. The next part is grabbing an object and coming back to the start point.
