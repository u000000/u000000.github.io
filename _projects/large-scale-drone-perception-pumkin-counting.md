## Overview
The main goal of the project is to calculate number of pumpkins which are grown on the field. Every operation is based on generated orthomosaic which was created using WebODM. Next, we cropped it to limit the data to process. Later we wrote a code that splits the orthomosaic into tiles. The final step was to perform proper pumpkin recognition and calculate how many of them were located in the area.
