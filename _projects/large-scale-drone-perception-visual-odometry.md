## Overview
Implemented a visual odometry system for drone trajectory estimation and sparse 3D reconstruction. Using ORB feature detection, essential matrix estimation, triangulation, PnP localization, and bundle adjustment, the project reconstructed the drone's flight path from video data and validated the results against recorded GPS measurements.
