## Overview
The purpose of this paper is to show how to communicate between FPGA and the CPU using BRAM and UART. Data transferred from UART port via FTDI (USB to serial UART converter) is read by the FPGA circuit and stored in BRAM memory. Then data from BRAM is read by the CPU and transferred back to PC via USB port.
