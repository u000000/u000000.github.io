## Overview
Developed a distributed wildlife monitoring system based on Raspberry Pi, ESP8266, and Raspberry Pi Pico. The system captures images using motion detection, external triggers, and scheduled events, automatically transfers data to a drone via Wi-Fi, and annotates collected images using a local vision-language model (LLaVA/Ollama). The project also includes autonomous recovery after power loss, rain detection with an automated lens wiper, a local web interface, secure file synchronization, and cloud-based metadata management.
