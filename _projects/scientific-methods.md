## Overview
The following paper aims to test 3 methods (GNSS, RTK, and Optical Flow) of landing fully autonomous UAV drones, with the goal of statistically evaluating their performance. This testing was carried out using a physical FPV drone at the HC Andersen airport in Odense, with the intent of using an RTK network operated by Quadsat. However, due to time constraints with the RTK network's availability an alternative was found using a publicly available RTK service - which had spotty coverage. Additionally, issues with the third-party Optical Flow hardware made it impossible to implement it before the scheduled test flights. Even so, 3 methods of landing were tested by substituting Optical Flow with manual landing executed by an experienced pilot.
